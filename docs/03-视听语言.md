## 3.1 六层字幕系统

这是全片最精密、也最值得借鉴的部分。

### 层级定义

| 层 | 用途 | 样式 | 位置 |
|---|---|---|---|
| **T1 主字幕** | 叙事陈述 | 宋体，两行居中，白 + 金色关键词 | 画面高度 76%–89% |
| **T2 引语** | 人物原话 | 加引号，略小 | 同上 |
| **T3 数据标注** | 大数字 + 小注 | 衬线体大数字（如 103,353）+ 下方小字 | 画面中央偏下 |
| **T4 角落计数** | 实时运算量 | 右上角小字"这一屏数到 3,680" | 右上 |
| **T5 资料说明** | 注明出处 | 左上小字 + 半透明底板 | 左上 |
| **T6 时间标** | 时间轴刻度 | 8月 / 10月 + 横轴 0 / 1/8 / 1/2 / 7/8 / 1 | 画面下三分之一 |

### 实测参数

| 参数 | 实测值 |
|---|---|
| 字幕区顶部 | 画面高度 **76.5%** |
| 字幕区底部 | 画面高度 **88.7%** |
| 文字块高度（两行，1078p） | 约 **154px** |
| 单行占比 | 55% 的帧是单行 |
| 两行占比 | 39% |
| 三行占比 | 15% |
| 金色关键词出现率 | **45% 的字幕帧里出现** |
| 金色词占比 | 字幕像素的 5%（中位） |

### 关键技术：累积式字幕（逐句生长）

句子不是整句弹出，而是先出现前半句，再把后半句接上去：

```
33s  一次风浪渡海前 他
36s  他以此向命运下注
     上帝绝不会让他
39s  他以此向命运下注
     上帝绝不会让他在死后白白享有一份虚假的荣耀
```

```
72s  它们散落在数轴上 看似毫无章法 拒绝被
75s  …拒绝被任何公式驯服
```

**效果**：像有人在你面前写字。这是"文学感"的来源，不是排版技巧。

### 关键词染色规则

每句挑 **1–2 个词**染金色：

| 句子 | 金色词 |
|---|---|
| 他看见一条**临界线** 并预言 所有的**零点** 都排列其上 | 临界线 / 零点 |
| 但**十万亿** 除以**无穷** 等于零 | 十万亿 / 无穷 |
| 一百零七年前 **星光偏折**验证了爱因斯坦 | 星光偏折 |
| 而今天 我们亲手造出的**硅基智慧** 替人类触碰到了**神迹** | 硅基智慧 / 神迹 |

**规律：金色给"概念名词"和"关键数字"，不给动词、不给连接词。**

## 3.2 色彩即叙事状态

按每 6 秒采样测得的平均色相：

| 段落 | 亮度 | 主色相 | 倾向 |
|---|---|---|---|
| 序章 6–30s | 17–56 | 30–63° | 暖褐（R>G>B） |
| 夜/海 36s | 33 | 210° | 蓝 |
| 数学 84–126s | 19–53 | 210–220° | 深蓝 |
| 日食 132s | **87** | 44° | 暖白（全片最亮之一） |
| 火 180s | **91** | 49° | 金橙（最亮） |
| **高潮 186–210s** | 15–37 | **154–189°** | **翠绿** |
| 落版 222–234s | 9–43 | 85–105° | 青绿 |

**色彩切换是硬切的，不是渐变。** 段落一换，色相就换，观众通过颜色就知道"进入新章节"。

## 3.3 镜头运动

### 肯·伯恩斯推拉

对静态素材镜头逐帧搜索缩放（可信样本）：

| 镜头 | 时长 | 缩放 |
|---|---|---|
| 日食底片 | 1.8s | +1.0% |
| 核查页 | 3.2s | −0.5% |
| 牛顿《原理》 | 1.5s | −1.0% |
| NYT 头版 | 4.0s | +2.5% |
| 地球夜面 | 4.0s | −6.0% |
| 手稿 | 8.3s | ≈ −5.5% |

**换算：约 0.2%–1.5% / 秒。**
这个速率在单帧上看不出来，连续看就是"画面在呼吸"。

### 运动类型分布

| 类型 | 镜头数 |
|---|---|
| 内部运动（粒子/图形/光标） | 37 |
| 平移 | 4 |
| 推拉 | 4 |
| 基本静止 | 3 |
| 闪帧 | 2 |

**没有花哨的运镜。** 80% 的画面靠"内部元素在动"，不是"镜头在动"。

## 3.4 剪辑语法

### 切点节奏

全片 **39 个硬切**，平均镜长 **6.0 秒**。但分布极不均匀：

| 区间 | 切点数 | 特征 |
|---|---|---|
| 0–53s | 10 | 每 5–7 秒一切 |
| **53.5–101.2s** | **0** | **连续长镜 47.8 秒，无硬切** |
| 101–234s | 29 | 逐渐加密，高潮段 10 秒 5 切 |

数学段落是一整段 47.8 秒的连续演化，用溶解、元素进出、镜头推近完成转场。**这段是全片最"高级"的地方——它给了观众思考的时间，而叙事段用快切维持信息速率。**

### 转场类型

1. **硬切**（绝大多数）
2. **闪帧**（0.2–0.5s 插入相关画面，共 4 处）
3. **黑场**（章节分隔，3 处）
4. **溶解**（数学段内部）
5. **闪白**（日食、火星）

没有花哨转场。

## 3.5 声音设计

### 结论：极简到极致

| 项 | 有/无 | 说明 |
|---|---|---|
| 旁白 | **无** | 全靠字幕 |
| BGM | **有** | 单一商业版权曲（The Cinematic Orchestra） |
| 音效 SFX | **基本无** | 检测高频瞬态，除开头 1.5s 录音杂音外未发现 whoosh/impact |
| 卡点剪辑 | **弱相关** | 切点处音频通量比随机时刻仅高 **20%** |

**这是一个重要发现：它没有做音效设计，也没有踩点剪辑。**

情绪全靠：
1. 一首现成的电影配乐
2. 音乐本身的强弱起伏
3. 画面节奏与音乐的**大致**同步

### 响度曲线

- 峰值 0.148（−16.6 dBFS），整体非常轻
- 曲线：开头极低 → 30–50s 渐强 → **55–70s 突然变轻** → 回升 → 180–200s 最高 → 结尾减弱
- **55–70s 变轻处，正好是数学长镜开头：音乐让位给画面**

### 高潮段的处理

168–200 秒（32 秒）**完全没有字幕**，只有音乐 + 蒙太奇（多米诺、人影、火星、钢笔、极光）。

**在最关键的 30 秒里撤掉文字。** 这是全片最重要的节奏规则。

## 3.6 后期处理链（逐层推断）

```
1. 素材层：档案图 / 截图 / 生成影像 / 程序图形
2. 调色：按段落上 LUT（琥珀 / 深蓝 / 翠绿）
3. 暗角：强，四周压到接近黑
4. Bloom：高光处泛光，不做大面积
5. 颗粒：细颗粒
6. 扫描线：部分镜头有极淡横纹
7. bokeh：档案镜头背景有虚焦光斑
8. 字幕：宋体 + 金色关键词 + 累积式动画
```
