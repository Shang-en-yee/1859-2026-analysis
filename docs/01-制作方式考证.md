## 1.1 结论

**不是 Anthropic 内部工具，也不是某个保密产品。**

创作者在 B 站简介里写得很清楚（经 API 完整抓取，非页面正则）：

```
本片由 GPT 构思剧本、搜集素材
由 Claude 用代码创作全部动画镜头并编译成片
```

```
配乐：The Cinematic Orchestra《Arrival of the Birds & Transformation》
```

## 1.2 分工还原

| 环节 | 执行者 | 产物 |
|---|---|---|
| 选题、叙事结构、52 镜编排 | 人 + GPT | 剧本 |
| 文案（字幕全文） | GPT | 约 1000 字 |
| 素材搜集 | GPT | 档案图/截图/影像清单 |
| 全部动画代码 | **Claude** | 渲染器 |
| 编译成片 | Claude | MP4 |
| 配乐选择、版权判断 | 人 | BGM |
| 伦理标注（哪一镜是设想） | 人 | 免责说明 |

**所谓"神秘编排能力" = 强文案 + 强执行 + 人的取舍。** 没有第四样东西。

## 1.3 三个反证

如果这是某家公司的内部工具，应当存在以下痕迹之一。实际上：

1. **第三方生态存在**：GitHub 上有大量同类「Claude Code 视频生成 skill」项目（如 vox-explainer-skill、video-director、code-video-director、xilo-opus-video）。若官方已有成熟工具，这些项目没有存在必要。
2. **无官方产品痕迹**：在 Anthropic 的公开产品线与发布物中检索不到视频生成工具。
3. **技术断面暴露**：片中 3D 场景（极光、地球）的质感与程序图形差距明显，说明没有统一的渲染后端，是多来源拼装。

## 1.4 一个关键判断：他们没有编排系统

**创作者是为这一支片子专门写的一套代码。**

推论依据：
- 画面风格高度定制（六层字幕、逐镜色彩、52 镜各自的构图），不像通用模板产物
- 若已有可复用的引擎，公开作品中应当出现同类风格的连续产出

这意味着：

| | 他们 | 工业化做法 |
|---|---|---|
| 渲染逻辑 | 每片重写 | 固定引擎 |
| 镜头实现 | 52 次一次性 | 模板复用 |
| 质检 | 无 | 指标 + 规则闭环 |
| 周期 | 约一周/支 | 目标 1–2 天/支 |

**他们的做法是手工艺。** 这既是这类作品质量高的原因（每一帧都被单独照顾），也是它难以规模化的原因。

## 1.5 对分析者（我们）的启示

1. **不要把"AI 做的"神秘化。** 拆开之后，是四个可分离的工种：写作、素材、排版、节奏。
2. **真正的门槛在文案。** "但十万亿 除以无穷 等于零"这种句子不是渲染器能生成的。
3. **素材决定天花板。** 这支片子 55% 的画面不是代码，是档案、截图、生成影像和实拍。
