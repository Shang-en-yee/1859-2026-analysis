## 2.3 素材构成

| 类型 | 秒数 | 占比 |
|---|---|---|
| 程序图形 | ~93s | **40%** |
| 档案（手稿/肖像/报纸/书籍） | ~41s | 18% |
| 截图（公告/新闻/核查页） | ~39s | 17% |
| 生成影像（烛火/海/极光/地球） | ~37s | 16% |
| 实拍 | ~16s | 7% |
| 黑场/闪帧 | ~8s | 3% |

**结论：程序图形占 40%，档案 + 截图占 35%，生成影像 16%，实拍 7%。**

纯代码能覆盖前 40%；其余 55% 是素材工程，7% 必须实拍。

## 2.4 文案写作法

| 手法 | 例子 |
|---|---|
| 明确时间锚点 | "1859 年 11 月 哥廷根"、"1900 年 巴黎" |
| 原话引用 | "至于证明 我试了几次没成 先放一放" |
| 具体数字 | 39 岁、167 年、一千七百四十万行、99.96% |
| 悬念句 | "但十万亿 除以无穷 等于零" |
| 拟人 | "它们散落在数轴上 看似毫无章法 拒绝被任何公式驯服" |
| 落点句 | "而今天 我们亲手造出的硅基智慧 替人类触碰到了神迹" |

**字数与节奏：**
- 全片字幕约 55–60 条，平均 18–22 字
- 原文 469 秒 → 全片平均约 2.1 字/秒（含量静默段）
- 单条实际阅读速度 2.0–5.5 字/秒，单条驻留 4–10 秒
- **两行是常态**，一行是强调，三行是信息密集段

> 注意区分：全片平均 2.1 字/秒 是把 32 秒静默段算进去的，不能当单条字幕的规范。

## 2.5 节奏设计

| 段落 | 平均镜长 | 手法 |
|---|---|---|
| 0–53s 历史 | 6–8s | 慢，每镜讲一件事 |
| 53–101s 数学 | **单一长镜 48s** | 零硬切，元素进出 |
| 101–170s 新闻 | 3–5s | 中速，信息密度高 |
| 170–186s 高潮 | **0.2–1.6s** | 快切蒙太奇 |
| 186–212s 绿光 | 4–9s | 慢回来 |
| 212–234s 落版 | 1.5–8s | 快→慢 |

最慢与最密相差 **240 倍**。

**另一条关键节奏规则：168–200 秒共 32 秒完全没有字幕。** 全片最关键的段落撤掉了文字，只留画面与音乐。
