## 一句话结论

**它不是"动画"，是用动画手法做出来的纪录片。**

三根支柱：**真实史料**（决定可信度）、**文案**（决定感染力）、**节奏**（决定情绪曲线）。
代码只是第三根支柱里的一小段。

## 制作方式：创作者自己说的

视频简介原文（经 B 站 API 完整抓取）：

> **本片由 GPT 构思剧本、搜集素材**
> **由 Claude 用代码创作全部动画镜头并编译成片**

> 配乐：The Cinematic Orchestra《Arrival of the Birds & Transformation》
> 史料与影像：公有领域馆藏、NASA、Pexels
> 新闻画面均为各机构与媒体页面的原始截图
> **两个 AI 做了这部片子**

也就是说：**没有秘密引擎，没有内部工具**——是两个通用模型 + 一个人。

| 环节 | 执行者 |
|---|---|
| 选题、叙事结构、52 镜编排 | 人 + GPT |
| 文案（字幕全文） | GPT |
| 素材搜集 | GPT |
| 全部动画代码 | **Claude** |
| 配乐选择、伦理标注 | 人 |

> 补充：简介中明确标注「片中'全部校验通过'一幕是本片的设想」，即虚构画面被主动声明。
> 这是叙事伦理的做法，值得学习。

## 本仓库的五个核心发现

### 1. 素材构成：40% 是程序图形，35% 是真实素材

按秒数统计（详见 [docs/02-叙事结构.md](docs/02-叙事结构.md)）：

| 类型 | 占比 |
|---|---|
| 程序图形（数学可视化/计数器/图表） | **40%** |
| 档案（手稿/肖像/报纸/书籍） | 18% |
| 截图（新闻/产品/核查页） | 17% |
| 生成影像（烛火/海/极光/地球） | 16% |
| 实拍 | 7% |
| 黑场/闪帧 | 3% |

**纯代码只能覆盖那 40%。** 剩下的 55% 是素材工程。

### 2. 字幕有六层，而且会"生长"

这是全片最精密、也最值得借鉴的系统。主字幕、引语、数据标注、角落计数、资料出处、时间刻度——六个层级同时工作。

关键动效是**累积式生长**：句子不是整句弹出，而是分 2–3 次接续出现，像有人在你面前写字。

```
33s  一次风浪渡海前 他
36s  他以此向命运下注
     上帝绝不会让他
39s  他以此向命运下注
     上帝绝不会让他在死后白白享有一份虚假的荣耀
```

完整规范见 [docs/03-视听语言.md](docs/03-视听语言.md)。

### 3. 色彩承担叙事

| 段落 | 主色相 |
|---|---|
| 序章（1859 手稿） | 琥珀 30–63° |
| 数学（临界线） | 深蓝 210–220° |
| 证据（日食/报纸） | 暖白 |
| **高潮（突破）** | **翠绿 154–189°** |
| 落版（地球） | 青绿 |

**段落一换，色相就换，硬切不渐变。** 观众靠颜色就知道进了新章节。

### 4. 节奏差 240 倍

| 段落 | 平均镜长 |
|---|---|
| 53–101s 数学段 | **单一长镜 48 秒，零硬切** |
| 170–186s 高潮 | **0.2–1.6 秒**（18 秒 14 个镜头） |

**快慢对比本身就是情绪曲线。** 快切给信息，长镜给思考。

另外：**168–200 秒共 32 秒完全没有字幕**，全片最关键的段落撤掉了文字。

### 5. 声音极简到极致

| 项 | 结论 |
|---|---|
| 旁白 | 无 |
| 配乐 | 单一商业版权曲 |
| 音效 SFX | **基本没有**（检测不到 whoosh/impact） |
| 卡点剪辑 | **弱相关**（切点处音频通量仅比随机高 20%） |

情绪全靠一首好音乐 + 画面节奏，**没有做音效设计，也没有踩点**。

## 量化对照

同一套算法测得的指标（详见 [docs/04-量化方法.md](docs/04-量化方法.md)）：

| 指标 | 参考片 | 说明 |
|---|---|---|
| 帧间差 frame_diff | 2.29 | 画面运动强度 |
| 运动帧占比 | 0.774 | 有运动的帧比例 |
| 结构覆盖率 | 0.381 | 信息密度 |
| 平均亮度 | 31.7 | |

**一个方法论教训：不要用"平坦区标准差"衡量信息密度。**
它会奖励噪点，也受整体亮度影响。换成"结构覆盖率"才反映真实的信息量。

## 这份分析可以用来做什么

1. **理解这类"AI 纪录片"是怎么被做出来的**——不是模型魔法，是文案 + 排版 + 素材 + 节奏
2. **作为制作同类作品的规范依据**——字幕层级、色彩状态、镜长分布都是可执行参数
3. **作为评价标尺**——四项指标可以直接用来检验自己的片子
